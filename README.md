# Valentine Static GitHub Pages Version

This folder contains a static version of the Valentine page designed for GitHub Pages hosting.

## Files

- `index.html` — page structure
- `styles.css` — styles
- `script.js` — interactivity
- `gifs/` — copied GIF assets

## Publish on GitHub Pages

1. Push this folder to a GitHub repository.
2. In GitHub, open the repository.
3. Go to Settings → Pages.
4. Choose the branch and root folder.
5. Save.

The site will be published at a URL like:

`https://<username>.github.io/<repository-name>/`
